## 🚀 Installation

### Option 1: Global Antigravity Install (Recommended)
Clone directly into your Antigravity skills directory:
```bash
git clone https://github.com/Muna555/antigravity-expert-brain.git ~/.gemini/config/skills/expert-developer-brain
```

### Option 2: Project-Level Link
Place inside `.gemini/skills/expert-developer-brain` in any repository.

## 🛠️ Quick Commands
- `/compact` : Compresses conversation history to recover speed and save tokens.
- `handoff` : Generates the 100% Lossless High-Density Brief for a fresh session.
- `audit` / `check` : Runs all programmatic hard-gate tests.
- `clean` : Cleans temporary scratch files and keeps git spotless.
- `suggest` : Asks the brain for proactive market, viral UI, and revenue optimization ideas.
- `update` : Triggers an online best-practice check for project dependencies.
- `immune` : Checks all Single-Failure permanent invariants to ensure zero bugs recur.
